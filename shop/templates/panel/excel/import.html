Nhập từ Excel

  1. Tải file mẫu (hoặc xuất danh sách hiện tại để sửa).
  2. Điền mỗi dòng 1 biến thể (SKU). Xem sheet “Hướng dẫn” trong file.
  3. Tải file lên → hệ thống kiểm tra và báo lỗi theo từng dòng, chưa ghi gì.
  4. Xem trước kết quả → bấm Xác nhận để ghi.
